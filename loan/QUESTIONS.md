# LOAN — Ten foundational questions

1. **Integrity:** How does a node verify that it has not been compromised?
2. **Authority:** What grants a machine the right to act?
3. **Identity:** How do nodes authenticate one another without central authority?
4. **Sovereignty:** How does each node retain absolute control over its own resources?
5. **Privacy:** What information must never leave a local node?
6. **Trust:** How is trust established, maintained and revoked?
7. **Autonomy:** How does a node resolve conflicting objectives independently?
8. **Resilience:** How does the network survive corruption, isolation and infrastructure failure?
9. **Accountability:** How can actions be independently verified without centralized surveillance?
10. **Evolution:** How can the network improve itself without compromising its foundational principles?

These questions precede implementation. The architecture must answer them, not merely acknowledge them.
