## Evidence rules

For each finding record: source title, issuing body, original date, retrieval date, URL, archive copy, exact page, claim supported, caveats, and next action.

Status labels: **primary document inspected**, **secondary source**, **lead**, **inference**, **unverified**. Nothing here is automatically labeled inspected simply because it was previously discussed.
