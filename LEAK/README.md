## Seven recurring weaknesses
1. Disclosed transaction roles but opaque **final retained exposure**.
2. Long-term fixed infrastructure costs versus variable usage revenue.
3. Repeated counting of the same asset through leases, collateral and financing.
4. Ledger balancing without independent transaction-population verification.
5. Missing identifiers, weak metadata and inconsistent release custody.
6. Media emphasis on deal size or announcement rather than cash settlement and final outcome.
7. Oversight findings without independently documented closure.
